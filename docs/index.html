반별 관리

학생 개인정보나 학교명을 넣지 말고 임의의 코드 사용을 권장합니다. 영문·숫자·-·_ 4~32자리.

선택된 반 없음

기기 등록 초기화를 누르면 그 반번호로 등록된 기기만 다음 정책 동기화 때 반등록이 해제됩니다. 이후 학생이 앱을 열면 새 고유반번호 입력창이 다시 나타납니다. 학년 변경 때 사용하면 됩니다.

학생 기기 설치 흐름

MDM으로 APK 설치 → 앱 최초 실행 → 고유반번호 입력 → 접근성 서비스 허용. 이후 반 ON/OFF와 사이트 정책은 중앙에서 자동 동기화됩니다.
